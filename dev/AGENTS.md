# Chronicle development workspace

The root `AGENTS.md` and durable development material in this directory are
tracked so Chronicle's engineering process travels with the repository.

- `agents/`: tracked role instructions
- `contracts/`: tracked component contracts
- `evidence/`: ignored temporary command output and artifacts
- `reports/`: tracked investigation, acceptance, and review reports
- `runs/`: ignored run manifests and process output
- `scratch/`: ignored disposable investigation material

Local roles are limited to developer, critic, investigator, integration, integration_critic, and progress_curator. The curator recommends Chronicle admission classifications but never writes or promotes history.

Promote every durable conclusion needed to understand, build, test, or maintain Chronicle into tracked source, schema, tests, examples, or documentation before accepting a component.
